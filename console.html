Sourcer

Built · CLI
Deal origination. Builds the target universe, scores every company 1–10 against the deal box with a one-line thesis, buckets A/B/C, and drafts the three-touch direct-to-owner sequence in Nathan’s voice. Writes to the shared pipeline DB; the CRM is where those leads are then worked.
Terminal — no web view yet

Analyst

Built · CLI
Deal underwriting. Spreads a CIM into a normalized EBITDA with every add-back itemised and rated accept / challenge / reject, builds the automation margin bridge, runs base/bear/bull returns, solves for the highest price that still clears 3.0x MOIC, and writes the one-page IC memo. Always ends on a number, never “it depends”.
Terminal — no web view yet
Sourcer and Analyst are dormant by default. No schedulers, no daemons, nothing sends. Every run is a manual command, drafts are stored rather than delivered, and the whole pipeline runs offline against a mocked model for $0 — they only make a paid call when a key is set explicitly. They switch on when capital is raised, not before.
Status labels are honest. “Built” means it runs today, and “CLI” means exactly that — a terminal tool with no web view, not a screen we have simply not linked. Nothing on this page is a placeholder for work that has not happened. The same rule applies inside Poly, where any figure we have not measured is shown as unmeasured rather than estimated. A console that flatters itself is not useful to the person reading it.
